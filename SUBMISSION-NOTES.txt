Native Android BMI Calculator built with Java and XML. It validates height in centimetres and weight in kilograms, calculates BMI as weight/(height in metres squared), and displays the value and Underweight, Normal, Overweight or Obese category. Classification uses the unrounded result. Decimal commas and Arabic digits are supported. Editing inputs clears the previous result; Reset clears the form. The calculated result survives Activity recreation.

Run: open the source folder in Android Studio, sync Gradle, and run the bmi module on Android 8.0/API 26 or later. Enter 175 cm and 70 kg, then tap Calculate BMI: expected result 22.86, Normal. Empty, zero, malformed and out-of-range inputs show validation errors. Accepted ranges are 50-300 cm and 10-700 kg. Adult BMI categories apply to ages 20+; this is an educational screening calculator, not a diagnosis.
